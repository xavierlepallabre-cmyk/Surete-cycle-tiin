Bilans et hypothèses

États de vapeur approchés, bilans massiques et énergétiques explicités. Vapeur vive supposée saturée sèche à ≈ 69 bar ; détentes HP et BP représentées par des enthalpies indicatives. La vapeur chauffante du GSS est prélevée sur la vapeur vive puis condensée : son débit découle du bilan de l’échangeur. Le soutirage régénératif est prélevé en sortie HP et son énergie est transférée à l’eau alimentaire.

Bilans : ṁvive = ṁBP + ṁsoutirage + ṁchauffage GSS ; Q̇GSS = ṁBP Δhréchauffage = ṁchauffage GSS (hvive − hpurge GSS) ; Q̇GV = ṁvive(hvive − halimentaire). Le rejet au condenseur est estimé par différence globale.

Limite de validation : pas d’équations IAPWS-IF97. Températures de saturation interpolées ; enthalpies approchées. Ne pas utiliser pour une étude de sûreté ni pour la conduite d’une tranche.

      Lire le code couleur

      Couleur : température (bleu froid → rouge chaud). Motif : tube plein + particules = eau liquide ; tube creux + traits rapides = vapeur ; tube creux + gouttes = vapeur humide (diphasique). Épaisseur : niveau de pression. Les particules avancent dans le sens de l’écoulement, plus vite à forte puissance.

      Parcours conseillé

      1. Cuve → pompes primaires → GV → pressuriseur. 2. Turbine HP → GSS → turbines BP → condenseur → poste d’eau → GV. 3. Auxiliaires et sauvegardes.
